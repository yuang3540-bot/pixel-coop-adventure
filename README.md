# 像素双人冒险（在线合作版）

这是一个可运行的双人在线像素风平台闯关小游戏。两位玩家通过同一个房间码连接，收集全部 5 颗宝石，然后一起走到右侧出口通关。

## 你需要准备
- Windows 电脑
- Node.js 18 或更高版本
- 一个代码编辑器（可选，记事本也能打开文件）

## 一、在自己电脑上运行
1. 安装 Node.js：访问 https://nodejs.org/ ，下载 LTS 版本并安装。安装时保持默认选项即可。
2. 解压本项目 ZIP。
3. 在 Windows 文件资源管理器中打开解压后的 `pixel_coop_adventure` 文件夹。
4. 点击文件夹地址栏，输入 `cmd` 并按回车，打开命令提示符。
5. 输入 `npm install` 并回车，等待依赖安装完成。
6. 输入 `npm start` 并回车。看到 `Pixel co-op game running on port 3000` 即表示启动成功。
7. 在这台电脑浏览器打开 http://localhost:3000 。

## 二、让同一 Wi-Fi 下的另一台设备加入
1. 两台设备连接同一个 Wi-Fi。
2. 在运行游戏的电脑上打开命令提示符，输入 `ipconfig`，找到当前 Wi-Fi 网卡的 `IPv4 地址`（例如 `192.168.1.8`）。
3. 另一台设备浏览器访问 `http://电脑的IPv4地址:3000`，例如 `http://192.168.1.8:3000`。
4. 玩家 1 创建房间后，把屏幕上的 4-6 位房间码告诉玩家 2；玩家 2 输入同样的房间码并加入。
5. 如果 Windows 防火墙弹出提示，允许 Node.js 在专用网络通信。

注意：这种方式只适用于同一局域网 / 同一 Wi-Fi，不等于跨城市互联网联机。

## 三、让不同网络的两个人真正联网
需要把这个 Node.js 项目部署到一台公网服务器。最简单的方式之一是使用支持 Node.js Web 服务和 WebSocket 的托管平台（例如 Render、Railway 或自己的云服务器）：
1. 把解压后的项目上传到 GitHub 仓库。
2. 在托管平台创建一个新的 Web Service，并连接该 GitHub 仓库。
3. Build Command 填 `npm install`；Start Command 填 `npm start`。
4. 不要手动固定端口；程序会自动读取平台提供的 `PORT` 环境变量。
5. 部署成功后，平台会给你一个 HTTPS 网站地址。把这个地址发给朋友，两个人打开同一个地址，再用房间码加入即可。

部署平台的免费额度和规则可能变化；请以平台当前说明为准。确保平台支持 WebSocket 长连接。

## 操作方式
- 玩家 1：A / D 移动，W 跳跃。
- 玩家 2：方向键 ← / → 移动，↑ 跳跃。
- 手机：使用页面下方的左右和跳跃按钮。
- 目标：收集全部 5 颗宝石，并让两名玩家同时站在右侧出口处。
- 任意玩家掉出地图会回到起点；点击“重新开始”可重置关卡。

## 项目结构
- `server.js`：房间、玩家状态、碰撞和游戏逻辑服务器。
- `public/index.html`：游戏画面、键盘 / 手机控制和界面。
- `package.json`：项目依赖和启动命令。

## 小提示
这是一份适合学习和继续扩展的入门版作品。它目前没有账号系统、聊天、持久化存档或反作弊机制。正式公开运营前应增加房间访问限制、输入校验和部署安全配置。
